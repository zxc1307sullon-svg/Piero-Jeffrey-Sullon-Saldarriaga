Justificación de la solución
La digitalización permitirá reducir duplicación de registros, optimizar tiempos de atención y generar reportes confiables. El uso de software abierto garantiza accesibilidad y sostenibilidad, mientras que los paradigmas de programación aseguran un diseño modular y escalable.
Articulación curricular
Saberes previos retomados: programación estructurada y orientada a objetos, diagramas UML, bases de datos relacionales, control de versiones (Git). Preparación para cursos posteriores: Ingeniería de Software (escalamiento de módulos), Seguridad Informática (protección avanzada de datos), Arquitectura de Sistemas (integración con plataformas del MINSA), Gestión de Proyectos de TI (planificación y ejecución en instituciones públicas).
